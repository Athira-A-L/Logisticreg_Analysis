# Logistics Regression Analysis

The objective of this project was to analyze breast cancer diagnostic data and classify tumors as malignant or benign. The dataset was preprocessed by converting categorical labels, checking missing values, and scaling features using StandardScaler. The data was split into training and testing sets to build a predictive model. A Logistic Regression model was implemented to perform the classification and generate predictions.he model performance was evaluated using accuracy score and classification metrics to assess prediction effectiveness.
